Sincronizar PC e celular

Os dados são criptografados com a sua senha antes de sair do aparelho e ficam guardados num repositório privado do seu GitHub. Nem o GitHub consegue ler o conteúdo.

Como configurar (faça uma vez)
  1. No GitHub, crie um repositório novo chamado rogal-dados, marque Private e a opção Add a README file.
  2. Abra github.com/settings/personal-access-tokens/new.
  3. Dê um nome (ex.: rogal-sync), em Expiration escolha a validade, em Repository access marque Only select repositories → rogal-dados.
  4. Em Permissions → Repository permissions → Contents escolha Read and write. Clique em Generate token e copie.
  5. Cole o token aqui, digite sua senha e clique em Conectar. No celular, faça o mesmo com o mesmo e-mail e senha.

O token só dá acesso ao repositório rogal-dados e fica guardado apenas neste aparelho.

Backup dos dados

O arquivo de backup é criptografado: só abre com a sua senha. Guarde uma cópia de vez em quando (Google Drive, pen drive...).
